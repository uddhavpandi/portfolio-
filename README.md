# Uddhav Pandi portfolio

A responsive, single-page portfolio for AI/ML internships. It is built with plain HTML, CSS, and JavaScript and has no build step or package dependencies.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

The `portfolio` folder is ready for a static host such as GitHub Pages, Cloudflare Pages, or Netlify. Upload the folder as-is. The resume, photos, AWS certificate, Summer University certificate, recommendation letter, and Lasya Enterprises project records are stored in `assets/`.

## Project screenshots

The screenshots you supplied are included locally in `assets/` and arranged in each project's workflow order. Use the arrows or thumbnails to browse a project's screenshots. Each project also links to its live application, and Nexua AI and Exam Grader link to their GitHub repositories.

## Content

Contact details and project links come from the supplied resume. The current AI/ML internship resume is included as `assets/uddhav-pandi-resume.pdf`. Replace that file if you revise the resume later.

The credentials section links to the supplied Udacity, University of Helsinki, AWS, and Udemy certificates. The local PDF records are included in `assets/`; the other certificate links require an internet connection.
